# Gateways 2026 Application

A production-ready Expo React Native application.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npx expo start
   ```

## Development Commands

- `npm run android` - Start on Android
- `npm run ios` - Start on iOS
- `npm run web` - Start on Web
